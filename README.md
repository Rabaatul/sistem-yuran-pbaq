# Laporan PAI - Laporan Perkembangan Murid Pendidikan Islam 📖✨

Satu laman perkembangan pembelajaran yang membantu ibu bapa dan murid melihat perjalanan akademik serta pencapaian **Pendidikan Islam (PBD)** dengan lebih jelas, kemas, dan interaktif.

## 🌟 Ciri-Ciri Utama
- **Rekod PBD 6 Bidang Pendidikan Islam**: Al-Quran & Hafazan, Akidah, Ibadah & Praktikal Solat, Sirah Nabawiyah, Adab & Sahsiah, dan Tulisan Jawi.
- **Interaktif Rubrik PBD**: Tekan kad mana-mana bidang untuk melihat perincian deskriptor TP1–TP6, bukti kekuatan, dan bimbingan rumah.
- **Graf Perkembangan Penggal**: Pertukaran graf antara Penggal 1, Penggal 2 (Semasa), dan Penggal 3.
- **Laporan & Ulasan Guru**: Panduan kekuatan murid, ruang penambahbaikan, dan pelan tindakan rumah.
- **Galeri Hasil Kerja Murid**: Portfolio tugasan tulisan Jawi, carta hafazan surah, scrapbook adab, dan amali solat dengan modal *lightbox*.
- **Cetak Laporan Rasmi (`window.print()`)**: Paparan helaian cetakan rasmi fizikal 2-muka surat untuk dokumen sekolah.
- **Localhost HTTP Server**: Mengandungi skrip `server.ps1` native PowerShell untuk terus menjalankan laman secara tempatan.

## 🚀 Cara Menjalankan Secara Tempatan (Localhost)
1. Buka PowerShell di dalam folder projek.
2. Jalankan skrip server tempatan:
   ```powershell
   powershell -ExecutionPolicy Bypass -File server.ps1
   ```
3. Layari [http://localhost:8000/](http://localhost:8000/) di dalam pelayar web anda.

## 🛠️ Teknologi
- **Core**: HTML5, Vanilla CSS3 (Design System Editorial + Playful), Modern ES JavaScript
- **Icons**: Lucide Icons
- **Fonts**: Google Fonts (*Plus Jakarta Sans* & *Amiri*)
