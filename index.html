Konfigurasi Google Apps Script URL

Untuk menghubungkan aplikasi ini ke Google Spreadsheet anda:

  1. Buka Google Spreadsheet anda yang mengandungi sheet MURID dan BAYARAN.
  2. Klik menu Extensions > Apps Script.
  3. Salin semua kod daripada file Code.gs di projek ini dan tampal ke skrip editor Apps Script.
  4. Tekan Deploy > New Deployment.
  5. Pilih type Web App, set Execute as: Me, dan Who has access: Anyone.
  6. Salin Web App URL yang terhasil.
  7. Buka file index.html dan gantikan nilai const API_URL dengan Web App URL anda.
